Overview

A simulator game built and deployed on Roblox by a 2-person team. I worked on the core gameplay loops, the interface design, and the systems that keep player progress.

What I built

  • Architected and deployed the full-stack game, using Claude Code to rapidly prototype and fine-tune Lua scripts for the core gameplay loops.
  • Designed interactive game UIs in Figma and implemented client-server networking.
  • Built the player economy, progression systems, and inventory data persistence.
  • Co-developed game mechanics, progression scaling, and system architecture, and ran code reviews to keep systems integrated.

Tools and technologies

Lua, Roblox, Figma, Claude Code
